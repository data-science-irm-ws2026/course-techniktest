# DHBW Data Science – Techniktest

Dieses private Repository dient ausschließlich dem Technikcheck in **Session 1**. Es enthält keine Projektdaten, keine API-Schlüssel, keinen Coding Agent und keine benotete Aufgabe.

## Ziel

Nach dem Test ist klar, ob dein GitHub-Zugang und ein persönlicher GitHub Codespace für Session 2 und 3 funktionieren. Der eigentliche Kursstart erfolgt später über das Kurs-Repository.

## Vorbereitung

1. Melde dich bei GitHub an oder erstelle ein persönliches GitHub-Konto.
2. Beantrage möglichst früh den GitHub-Education-Status oder prüfe ihn unter [GitHub Education](https://github.com/settings/education/benefits). Halte dafür einen Hochschulnachweis bereit.
3. Öffne dieses Repository über den Link der Lehrperson. Es ist privat; der Zugriff erfolgt nur über die Einladung beziehungsweise die DHBW-Kursorganisation.

## Technikcheck in Session 1

1. Klicke auf **Code → Codespaces → Create codespace on main**.
2. Falls GitHub eine Maschinenwahl zeigt, wähle mindestens **2 Core**. Das Repository fordert dies als Mindestgröße an.
3. Warte, bis der Codespace vollständig geöffnet ist.
4. Öffne das Terminal und führe aus:

   ```bash
   bash scripts/check-setup.sh
   ```

5. Die Ausgabe muss mit **`[OK] Technikcheck bestanden.`** enden.
6. Melde anschließend nur deinen Status:
   - **Grün:** Codespace und Startcheck laufen.
   - **Gelb:** Education-Antrag oder Zugang noch offen.
   - **Rot:** Anmeldung oder Codespace-Erstellung blockiert.

## Was du nicht tun sollst

- Keine Zugangsdaten, API-Schlüssel, Zahlungsdaten oder personenbezogenen Daten eintragen.
- Keine privaten oder kursbezogenen Daten hochladen.
- Keine Erweiterungen oder Tools nachinstallieren.
- Nach dem Test den Codespace stoppen oder löschen, wenn du ihn nicht mehr brauchst.

## Einordnung

Dieser Test prüft nur GitHub und Codespaces. Er aktiviert keinen kostenpflichtigen Dienst, konfiguriert keine Provider und ersetzt weder die späteren Team-Repositories noch die Projektarbeit.

Bei einem gelben oder roten Status meldest du dich in der Session direkt bei der Lehrperson. So bleibt vor Session 2 ausreichend Zeit für eine Lösung.
